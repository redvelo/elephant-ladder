# One Small Step

A small demo meant to demonstrate interactivity. Modeled as a school text book it includes a video of Apollo 11, a remote image, a self-grading quiz using browser storage, a form, and word count game that runs in a web worker.

 `public/sample` holds the book.

Build from `src/` with `python3 demos/one-small-step/build.py`
